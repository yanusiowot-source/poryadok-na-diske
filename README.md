# Порядок на диске

Вечерняя работа на этом компьютере. В сеть ничего не уходит. Ничего не удаляет.

## Вечер

Двойной щелчок по `vecher.bat` — или в Git Bash:

```bash
cd ~/poryadok-na-diske
git pull
bash poryadok.sh vecher
```

Откроется ночная карта вашего диска. Под ней — сегодняшние слова.

## Дальше, если сами захотите

По одной команде:

```bash
bash poryadok.sh plan
bash poryadok.sh kopiya
bash poryadok.sh soglasen
```

`soglasen` спросит «согласен» вслух. Пачкой не выполняется.

Трогает файлы только после ясных слов «согласен».
