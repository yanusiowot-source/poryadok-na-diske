# Порядок на диске

Вечерняя работа на этом компьютере. В сеть ничего не уходит. Ничего не удаляет.

В Git Bash, в папке проекта:

```bash
cd ~/poryadok-na-diske
git pull
bash poryadok.sh idilliya
bash poryadok.sh chudo
```

`idilliya` — вечерняя картина словами.
`chudo` — ночная карта вашего диска в браузере. Ничего не удаляет.

Дальше, если сами захотите:

```bash
bash poryadok.sh plan        # план. файлы ещё на месте
bash poryadok.sh soglasen    # выполнить план
bash poryadok.sh kopiya      # запасная копия «Загрузок»
```

Трогает файлы только после `soglasen`.
