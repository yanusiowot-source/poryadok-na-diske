# Порядок на диске

Вечерняя работа на этом компьютере. В сеть ничего не уходит. Ничего не удаляет.

В Git Bash:

```bash
cd ~/poryadok-na-diske
git pull
bash poryadok.sh vecher
```

Откроется ночная карта вашего диска. Под ней — вечерняя картина словами. Можно показать матери.

Дальше, если сами захотите, **по одной команде**:

```bash
bash poryadok.sh plan        # план. файлы ещё на месте
bash poryadok.sh kopiya      # запасная копия «Загрузок». ещё не копирует
bash poryadok.sh soglasen    # спросит «согласен» вслух
```

Трогает файлы только после ясных слов «согласен».
